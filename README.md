How to run:
Place the provided "pa2.py" along with a formatted "POLICY.yaml" and "DEVICES.xml" into the same directory/folder. 
3 Files placed, will run with this command in a python supported terminal: "python pa2.py DEVICES.xml POLICY.yaml"

A audit.json file will be generated in the same directory where the command was run.
